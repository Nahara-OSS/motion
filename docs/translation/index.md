## Guidelines

These are guidelines that you should consider when translating the user manual
to a specific language.

- Most people looking for translated user manual would only care about the
  editor, so anything related to engine _may_ be omitted.

- When translating the quick start guide or editor introduction, please include
  a short guide on how to change the language to the one in the manual, as auto
  language detection might not work on some devices.

- Anything inside `bonus/` are not quite important to translate, since these are
  mostly technical docs (eg: the scene architecture) and philosophical concepts
  (eg: why Nahara's Motion is free). The one that might want to read this are
  most likely understood English to begin with.
